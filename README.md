# 🌱 FinWise AI — Personal Financial Analysis & Smart Budget Assistant

A LangChain + Streamlit FinTech prototype. You enter one month of income and expenses; **Python**
calculates the ratios and a rule-based score; an **OpenAI model through LangChain** turns those numbers
into structured, educational budgeting insights and a streamed written recommendation.

> ⚠️ **Educational use only.** FinWise AI is not financial, investment, tax or legal advice. It does not
> connect to bank accounts, move money or guarantee any outcome. Talk to a qualified financial
> professional before making money decisions.

---

## 1. Setup

Requires **Python 3.10+**.

```bash
# 1. Create and activate a virtual environment
python -m venv .venv
# Windows:  .venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Add your OpenAI key
cp .env.example .env          # Windows: copy .env.example .env
# then edit .env:  OPENAI_API_KEY=sk-...
```

Get a key at <https://platform.openai.com> → API keys. `.env` is listed in `.gitignore`, so it is never committed.
If you don't create a `.env`, you can paste a key into the sidebar (it stays in the browser session only).

## 2. Run

```bash
streamlit run app.py
```

Open <http://localhost:8501>. To try the assignment's test cases, open **Quick fill → Test scenarios**,
load one, and select **Analyse my finances**.

**Docker (optional):**

```bash
docker build -t finwise-ai .
docker run -p 8501:8501 --env-file .env -v finwise-cache:/app/data finwise-ai
```

**Tests (no API key needed — a fake chat model is used):**

```bash
pip install -r requirements-dev.txt
python -m pytest
```

## 4. How it works

```
Form ─► financial_calculator.py ─► build_prompt_inputs()
          (Python: totals, ratios,        │
           preliminary score, flags)      ▼
                            ChatPromptTemplate = SystemMessage(role + safety rules)
                                           + HumanMessage(PromptTemplate with the numbers)
                                          │
                                          ▼
                            LLMChain(ChatOpenAI in JSON mode)
                                          │
                                          ▼
                 utils.parse_financial_json() ─ valid? ─► dashboard
                          │ invalid                         │
                          ▼                                 ▼
                 one automatic repair call       llm.stream() ─► st.write_stream()
                          │ still invalid                (written recommendation)
                          ▼
                 rule-based fallback (clearly labelled)
```

### Python calculations vs AI insights

| | Python (`financial_calculator.py`) | AI (`chains.py`) |
|---|---|---|
| What | Total expenses, remaining income, savings ratio, expense ratio, debt share, preliminary score, warning flags, goal tracker | Health score, risk level, spending observations, priorities, recommendations, savings strategy, action plan, written advice |
| Deterministic? | Yes — same inputs, same outputs | No — wording can vary |
| Can be wrong? | Only if the formula is wrong (covered by tests) | Yes — it can misjudge; treat it as a suggestion |
| Shown as | **"Calculated in Python"** tag | **"Generated by AI"** tag |

The model receives the Python numbers as facts and is told not to recalculate them. Both scores are
shown side by side on a ruler, so you can see if the AI disagrees with the rule-based score.

**Formulas** (division by zero is guarded — 0 income gives 0% ratios and a score of 0):

```
total_expenses    = sum(all 10 expense categories)
remaining_income  = monthly_income - total_expenses
savings_ratio     = savings / monthly_income * 100
expense_ratio     = total_expenses / monthly_income * 100
preliminary_score = savings (30) + money left over (25) + expense ratio (25) + debt burden (20)
```

| Component | Full points | Zero points |
|---|---|---|
| Savings ratio (30) | ≥ 20% of income saved | 0% |
| Money left over (25) | ≥ 20% of income left | 0 or negative |
| Expense ratio (25) | ≤ 50% of income spent | ≥ 100% |
| Debt burden (20) | repayments ≤ 10% of income | ≥ 40% |

Score bands (educational): 80–100 strong · 60–79 generally healthy · 40–59 needs improvement · below 40 high attention.
The rule-based risk is HIGH whenever expenses exceed income or debt repayments reach 40% of income.

### LangChain concepts used

| Concept | Where |
|---|---|
| `ChatOpenAI` | `chains.get_llm()` |
| `SystemMessage` / `HumanMessage` / `AIMessage` | `chains.build_conversation()` (follow-up chat) and `build_message_demo()` (shown under *Under the hood*) |
| `PromptTemplate` | `prompts.ANALYSIS_PROMPT` — all 8 required variables + schema |
| `ChatPromptTemplate` | `prompts.ANALYSIS_CHAT_TEMPLATE` (system + safety + human built from the PromptTemplate), `NARRATIVE_CHAT_TEMPLATE` |
| `LLMChain` | `chains.build_analysis_chain()` |
| JSON output | JSON mode + Pydantic validation in `utils.parse_financial_json()`; repair + fallback |
| Streaming | `chains.stream_recommendations()` → `st.write_stream()` (also for follow-up answers) |
| Caching | `cache_manager.configure_cache()` with `set_llm_cache()` |

> **Note on `LLMChain`:** the assignment requires it, but LangChain has deprecated it in favour of
> `prompt | llm`. In LangChain 1.x it lives in the `langchain-classic` package, which is why that package
> is in `requirements.txt`. `chains.py` imports it from either location.

### Safe JSON parsing

`parse_financial_json()` never crashes. It:
1. removes Markdown fences and text around the JSON and finds the first balanced `{…}` object;
2. tolerates trailing commas;
3. validates with Pydantic: clamps the score to 0–100 (and reads `"85 points"`), normalises the risk level
   to LOW/MEDIUM/HIGH (`"moderate"` → MEDIUM), turns strings or numbered text into lists;
4. reports missing keys.

If parsing still fails, the model gets one chance to fix its own output; after that a rule-based analysis
built from the Python numbers is shown with a clear warning.

## 5. Caching

Choose the cache in the sidebar. `set_llm_cache(...)` registers **one global cache**; LangChain looks up
every request (prompt + model settings) before calling the API.

| | InMemoryCache | SQLiteCache |
|---|---|---|
| Stored in | RAM (memory) | A file on disk (`.langchain_cache.db`) |
| Speed | Fastest | Fast, slightly slower |
| Survives restart? | No | Yes |
| Best for | One session | Reusing across sessions |

To see it working: run an analysis, then select **Analyse my finances** again without changing anything.
The caption under *AI insights* changes from "fresh API call" to "served from cache — no new API call",
and the time drops to milliseconds. Changing any number, the model or the temperature creates a new cache
entry. The sidebar shows how many responses are stored and lets you clear the cache.

## 6. Features

**Required**
- Form with income, ten expense categories, monthly savings, goal and currency (tabs, columns, form).
- Python calculations with divide-by-zero guards and warning flags.
- `st.metric` overview, AI health score with progress bar, risk level, spending analysis, priorities,
  budget recommendations, savings strategy and next-month plan (tabs, expanders, info/warning boxes).
- Streamed written recommendation.
- Sidebar: project info, disclaimer, model and temperature, cache selection, reset session.
- Disclaimer in the header, sidebar, footer and PDF.

**Bonus**
- Expense charts (bar + donut).
- CSV upload (`category, amount[, month]`), with category names matched automatically — try `sample_data/expenses_sample.csv`.
- Month-to-month comparison (from CSV months) and run history with a score chart.
- PDF report and JSON export.
- Financial goal tracker (progress and estimated months to goal).
- Follow-up conversation that remembers earlier turns.
- 10 currencies.
- Docker deployment.
- "Under the hood" tab showing the exact messages, prompt variables, raw JSON and validation notes.

## 8. Troubleshooting

| Message | Fix |
|---|---|
| "API key was rejected" | Check `OPENAI_API_KEY` in `.env`, then restart Streamlit. |
| "Model isn't available" | Pick another model in the sidebar. |
| "Rate limit or quota reached" | Check billing/limits on platform.openai.com. |
| Deprecation warnings in the terminal | Expected: `LLMChain` and `langchain-community` are being phased out by LangChain; both still work. |
